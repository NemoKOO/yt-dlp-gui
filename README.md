# 視頻音頻字幕下載 MVP v0.6.1（Windows x64）

這是一箇面向普通 Windows 用戸的 yt-dlp 圖形界面。它把複製鏈接、選擇 MP4/MP3/SRT、分類保存和 Cookies 選項放進一箇窗口，不要求用戸輸入命令。本項目不是 yt-dlp 官方産品。

該版本爲輕量便攜包，**不隨包重新分發 yt-dlp、ffmpeg 或 deno 的二進制文件**。程式啓動後，首先檢查系統PATH中是否包含yt-dlp、ffmpeg 或 deno 的路徑信息，如未找到，詢問是否從各項目的官方發佈網址下載所需組件；安裝完成後，所有文件都保留在程式目録，不修改系統 PATH，也無需管理員權限。

建議在 Windows 10/11 x64 上使用。**Windows 7 不受支持**：當前 yt-dlp 官方獨立程式要求 Windows 8 或更新版本；本界面會在 Windows 7 上啓動前明确提示，不會繼續安裝不兼容組件。Windows 8/8.1 的整套組件未做兼容性驗證。

## 第一次使用

1. 完整解壓 Release 中的 `yt-dlp-gui-v0.6.1-windows-x64.zip`，不要直接在壓縮包裡運行。
2. 雙擊 `yt-dlp-gui.exe`。
3. 首次運行會列出缺少的組件。點擊「是」後開始下載，完整下載量約 250 MB（ffmpeg文件較大，請耐心等待）。
4. 依次下載程式並校核其官方 SHA-256、檢查 Windows 可執行文件格式，再放入程式目録。下載或校驗失敗的文件不會安裝。
5. 安裝中斷後可以再次點擊「檢查運行組件」，已經成功安裝的組件不會重複下載。

每箇組件先嘗試首選官方綫路；連接超時、403、404或校驗失敗時會自動重試，再切換可信備用綫路。不同綫路的文件分別使用其對應的官方校驗清單，**不會使用不明網盤或第三方加速鏡像**。

| 組件 | 首選來源 | 備用來源 |
| --- | --- | --- |
| yt-dlp | `yt-dlp/yt-dlp` 最新穩定版 | 同一官方倉庫的已知穩定版本 |
| FFmpeg / FFprobe | `yt-dlp/FFmpeg-Builds` | 其上游項目 `BtbN/FFmpeg-Builds` |
| Deno | `denoland/deno` GitHub Release | Deno 官方 `dl.deno.land` CDN |

如果自動安裝一直失敗，也可以從 `THIRD_PARTY_NOTICES.md` 列出的官方項目手動下載 Windows x64 文件，將 `yt-dlp.exe`、`ffmpeg.exe`、`ffprobe.exe` 和 `deno.exe` 放在 `yt-dlp-gui.exe` 旁邊。

## 下載視頻、音頻和字幕

1. 粘貼普通視頻網址，或直接粘貼帶前後文字的抖音分享文案。界面會顯示自動識別出的第一箇 `http/https` 網址。
2. 點擊「視頻 MP4」「音頻 MP3」或「字幕 SRT」。視頻模式可選擇「自動（原有選擇）」或「優先 360p/480p/720p/1080p/1440p（2K）/2160p（4K）」。字幕模式可選擇簡體中文、繁體中文或英文，每次只請求一種語言。
3. 選擇保存根目録，點擊「開始下載」。文件分別進入 `mp4`、`mp3`、`subtitles` 子目録，降低不同類型文件重名覆蓋的風險。
4. 完成後點擊「打開保存目録」。

網址輸入框采用「粘貼即替換」：無論使用 `Ctrl+V`、右鍵粘貼還是 `Shift+Insert`，新內容都會直接替換輸入框裡的舊內容，不需要先手動清空。若通過其他方式使輸入框中同時存在多箇網址，程式使用最後一箇網址。這項處理用於避免換第二條視頻時仍重複讀取第一條網址。

分辨率選項是**優先目標**，不是強制輸出的精确畵質：例如選「2160p 優先」，片源只有 1080p 就下載 1080p；不會把低畵質放大。yt-dlp 會優先選不高於目標的最佳畵質；如果片源只提供更高畵質，則選擇它提供的最低畵質。這箇排序按視頻較短邊計算，橫屛和竪屛都適用。選擇畵質時，文件名會包含實際寛高（如 `1920x1080`），避免再次選擇其他畵質時被原有同名 MP4 阻止。若下載到 AV1、VP9 等新編碼的 MP4，舊設備未必能播放，軟件不會重新編碼視頻。

默認只下載單箇視頻。勾選「下載整箇播放列表」前，請先确認列表大小。並非每箇視頻都有所選語言字幕；程式不會憑空生成視頻中不存在的字幕。

字幕下載後會檢查 VTT，並使用 FFmpeg 補做 SRT 轉換。即使某次字幕請求被限流或 yt-dlp 中途報錯，也會轉換已經下載到本地的 VTT。若提示 HTTP 429，請稍後再試，避免短時間連續請求。

## Cookies、抖音和更新

平時不要勾選「讀取 Firefox Cookies」。只有網站提示登録或驗證時，先在 Firefox 中打開目標視頻並刷新，再勾選重試。Cookies 可能包含登録狀態，不要公開完整日志、瀏覽器資料或 Cookies 文件。每次下載結束後，該選項會自動取消。

抖音經常要求新鮮 Cookies，但不一定要求登録。即使提供 Cookies，網站接口、反自動化策略或地域限制也可能導致失敗。軟件不能繞過 DRM、訪問權限或網站規則。

「檢查運行組件」會确認四箇文件是否存在；組件完整時，可以繼續調用 yt-dlp 官方的 `-U` 自更新。該操作只更新 yt-dlp，不更新界面、FFmpeg 或 Deno。GitHub 返回 403 時通常是臨時限流，可稍後重試。

## 安全和隱私

- 組件只通過代碼中列出的 HTTPS 地址下載，並在安裝前驗證對應官方 SHA-256。
- 下載過程不會生成或上傳 `cookies.txt`；需要時由 yt-dlp 直接讀取本機 Firefox 數據。
- 安裝緩存和 yt-dlp 運行臨時文件放在程式目録的工作文件夾中，正常結束後組件下載緩存會删除。
- 本程式沒有代碼簽名，Windows 第一次運行可能顯示 SmartScreen 提示。請從項目自己的 GitHub Release 下載，並核對 Release 提供的 SHA-256。
- 請僅下載你有權訪問和使用的內容，遵守網站條款和當地法律。

## 已知限制

- Windows 7 無法運行當前官方 yt-dlp 獨立版。`PYI ... python310.dll` 報錯來自 yt-dlp 的 Python/PyInstaller 運行環境，並不意味著只缺少一箇 DLL；單獨安裝 Python 或複製 DLL 不會修復系統兼容性。舊版/非官方組件組合需要另行維護和實際測試，不包含在本公開版中。
- 僅面向 Windows x64；Windows ARM64 暫未提供原生組件組合。
- 不保證「全網」或所有視頻都能下載。站點頁面、接口、權限和限流會不斷變化。
- 暫無清晰度細選、任務隊列、下載歷史和 GUI 自動更新。
- 播放列表進度條顯示當前文件進度，不是整个列表總進度。
- 取消視頻下載可能留下 `.part` 文件；組件安裝階段目前不可從界面中途取消。
- 使用 `--ignore-config`，不會讀取用戸的 yt-dlp 全局配置，以保證界面選項和保存路徑可預測。
- 只支持直接讀取 Firefox Cookies，不支持 Windows Chrome App-Bound Encryption。

## 構建與測試

源碼文件包括 `Program.cs`、`ComponentInstaller.cs`、`Tests.cs` 和 `build.ps1`。在 Windows PowerShell 中執行：

```powershell
powershell -ExecutionPolicy Bypass -File .uild.ps1
```

構建腳本使用 Windows 自帶的 .NET Framework C# 編譯器，不需要另裝 .NET SDK。測試覆蓋參數生成、網址提取、分類目録、VTT→SRT、本地中文編碼、組件缺失檢測、兩種官方校驗清單格式、壓縮包定向提取及備用綫路配置；常規構建測試不會下載大型組件。
